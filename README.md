# chainResilience: Supply Chain Risk & Bottleneck Analytics

## Executive Summary

**chainResilience** is an end-to-end data analytics framework built to diagnose supply chain vulnerabilities, quantify vendor risks, and detect operational bottlenecks. Developed as part of the **Digital Egypt Pioneers Initiative (DEPI)** Data Analytics track, this project transforms complex, multi-source supply chain data into actionable strategic insights.

### Key Objectives
- **Identify Bottlenecks:** Pinpoint root causes of delays across shipping routes, fulfillment centers, and inventory handling.
- **Supplier Risk Assessment:** Evaluate vendor reliability using custom OTIF (On-Time In-Full) metrics and historical lead-time variance.
- **Inventory & Fulfillment Optimization:** Provide data-driven visibility to minimize stockouts and reduce order-to-delivery cycle times.

### Tech Stack
`Python (Pandas, NumPy, Seaborn)` • `SQL (Data Modeling & KPIs)` • `Power BI / Tableau (Interactive Dashboards)` • `Git & GitHub`
